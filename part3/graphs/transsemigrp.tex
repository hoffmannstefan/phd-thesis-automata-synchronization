For transformation semigroups $S \le_S \mathcal T_n$
we define the digraph \label{def:graph_IS}
$
I(S) = (V, E)
$
with vertex set $V = [n]$ and edge set $E$ equal to
\[
	\{ (p,q) \mid  \text{ $p \ne q$ and there exists a simple idempotent $t \in S$ with $\applyfunc{p}{t} = q$} \}.
\] 

Note that the Rystsov graph is defined only for SI-automata, whereas the above construction applies to arbitrary transformation semigroups.

We also extend $\Gamma_1(\mathcal A)$ to transformation semigroups in the obvious way
by letting $\Gamma_1(S)$ be the digraph
with vertex set $[n]$ and edge set
\[

\{ (p, q) \mid \exists t \in S : \{p\} = \excl{t} \text{ and }  \dupl{t} = \{q\} \}.
